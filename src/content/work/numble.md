## The project

During my software engineering internship at Numble in Antwerp, I built a full-stack event management application, from the database to the user interface.

## What I built

- **Back end:** REST APIs in .NET 8 on top of SQL Server.
- **Front end:** a dynamic Vue 3 interface using Pinia for state, Axios for API calls and Vue Router for navigation.
- **Sign-in and permissions:** Azure AD B2C for secure login, with role-based access to decide who can do what.
- **Notifications:** an event-driven notification system built on Azure Service Bus and Azure Functions.
- **Delivery:** CI/CD pipelines and version control with Git and Azure DevOps.

## How we worked

The team worked in an Agile way, and I tracked my progress in Jira.
